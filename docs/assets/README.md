# Repository brand assets

The README wordmarks use the application's original TGD monogram and outlined
Instrument Sans lettering. Separate light/dark SVGs keep contrast on GitHub in both
themes without loading a web font. Instrument Sans attribution and SIL OFL 1.1
are preserved in `frontend/src/app/fonts/` and `NOTICE.md`.

Workspace screenshots show the current CADETS interface. Historical research
browser evidence remains under `backend/results/dashboard_validation/`.
