# Source and artifact provenance

The application was assembled from the working TGDetect checkout based on upstream commit `d83f2eab2c84394a6e9677fd9545dc15470bd573` of [MaheshMarathe005/TGDetect](https://github.com/MaheshMarathe005/TGDetect/tree/d83f2eab2c84394a6e9677fd9545dc15470bd573). Frontend improvements from the local design work are included.

The new repository is independent of `Pratham2511/TGDetect-Temporal-Graph`. Its contents and Git history were not rewritten or pushed to during this publication.

The original package inventory and packaging validation record are retained as `upstream-package_manifest.json` and `upstream-validation.json`. They describe the upstream layout and historical checks. The current source inventory, data inventory, and validation record are at the repository root.

Backend Python and research files retain their original contents. Original research/result JSON, logs, diagrams, and reference files are preserved. Historical `/study/...` or other original experiment paths are provenance rather than current local installation paths. `backend/results/dashboard_validation/` contains historical application evidence; current interface screenshots are in `docs/assets/`.

The unused Prisma scaffold and database commands, root `mock_backend.py`, old setup documents with machine-specific paths, tracked local `.env`, dependencies, build output, caches, and local uploaded datasets are excluded from this new source repository. The retained `/legacy` interface is explicitly documented as requiring separate absent artifacts.
